READY TO USE
================================================================================
The project is production-ready and can be deployed using:

1. Docker Compose (Local Development):
   $ cp .env.example .env
   $ docker-compose up -d

2. Maven (Local Java):
   $ mvn spring-boot:run -Dspring-boot.run.profiles=dev

3. Docker (Production):
   $ docker build -t config-service:1.0.0 .
   $ docker run -d -p 8888:8888 config-service:1.0.0
