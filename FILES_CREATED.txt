HOW TO USE
================================================================================

1. Quick Start (Docker):
   docker-compose up -d
   ./scripts/setup-keycloak.sh
   ./scripts/test-api.sh

2. Local Development:
   ./scripts/start-dev.sh
   mvn spring-boot:run

3. Build for Production:
   mvn clean package
   docker build -t auth-service:1.0.0 .
